# Glossary

The project's domain terms. One concept has one word, in code, docs and UI (see "Naming" in
`AGENTS.md`). Add a term when a new domain concept appears. Add the words it replaces under
"Retired words".

## Terms

- **term**: what it means, in one sentence. Where it appears in the code, if that helps.

## Retired words

- `old word`: use **term** instead.
